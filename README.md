# Python数据分析实战项目
## 项目简介
本项目使用Python完成多组数据分析实战，基于Pandas做数据清洗、数据处理，Matplotlib实现数据可视化，包含RFM用户分层、销售数据分析、股票数据、用户行为分析等案例。
全部代码在Jupyter Notebook中编写，附带原始数据集与可视化结果图片。

## 技术栈
- Python
- Pandas 数据处理
- Numpy 数值计算
- Matplotlib 数据可视化
- Jupyter Notebook

## 目录说明
```

├── *.ipynb          # Jupyter 代码笔记
├── *.csv/ *.xlsx   # 原始数据集
├── *.png            # 可视化输出图表
├── *.md             # 学习笔记
├── .gitignore       # Git 忽略配置
└── requirements.txt # Python 环境依赖

```

## 如何运行
1. 克隆仓库
```bash
git clone https://github.com/lizhi2005/vibecoding-claudecode.git
cd vibecoding-claudecode
```

2. 安装依赖

```
pip install -r requirements.txt
```

3. 启动 jupyter

```
jupyter notebook
```

## 项目案例

1. RFM 模型用户分层分析
2. 优衣库销售数据分析
3. 股票数据可视化
4. 城市空气质量数据分析
5. 多维度 Matplotlib 绘图实战

## 总结

通过多个真实数据集练习，掌握数据读取、缺失值处理、数据筛选、聚合统计、可视化绘图，完成完整数据分析流程。

```
